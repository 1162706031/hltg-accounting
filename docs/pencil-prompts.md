## 第 1 批：基础页面 (6 个)

### 1. 登录页 `/login`
- 居中卡片布局
- 标题 "旭峰新材料 综合管理系统"
- 用户名输入框
- 密码输入框
- 登录按钮
- 背景纯色或渐变

### 2. 工作台 `/` (Dashboard)
- 顶部 Header (用户名/角色/退出)
- 左侧 Sidebar (导航菜单 工作台/往来单位/物品管理/冶炼加工/外协加工/采购管理/销售管理/库房管理/用户对账/财务中心 + 分隔线 + 系统设置/用户管理/操作日志/审核中心)
- 右侧内容区上方 Tab Bar
- 内容区：顶部 3 个统计卡片横排（往来余额概览/本月冶炼批次/本月外协批次）
- 内容区：下方最近录入记录表格（时间/类型/批次/单位/金额）

### 3. 往来单位管理 `/parties`
- 列表页：工具栏 (+新建单位/批量删除)、筛选栏 (角色☑客户☑供应商☑外协厂 + 搜索框)、表格 (名称/简称/角色/联系人/电话/应收余额/应付余额/操作)
- 新建/编辑 Modal：单位名称、简称、角色三选、联系人、电话、地址、备注
- 余额展开面板（点击单位名称展开）：单位名+余额汇总 + 明细表格（类型/批次号/业务摘要/借方/贷方）

### 4. 物品管理 `/items`
- 列表页：工具栏 (+新建物品/批量删除)、筛选栏 (类型下拉+状态下拉+搜索)、表格 (名称/类型/规格/单位/状态/备注/操作)
- 新建/编辑 Modal：名称、类型选择、规格、默认单位、备注

### 5. 用户管理 `/users` (admin only)
- 列表页：工具栏 (+新建用户/批量删除)、搜索、表格 (用户名/姓名/角色/状态/创建时间/操作)
- 新建/编辑 Modal：用户名、密码、姓名、角色选择

## 第 2 批：核心业务页面 (4 个)

### 6. 冶炼加工列表 `/smelting`
- 工具栏 (+新建冶炼批次/批量删除)
- 筛选栏：类型下拉(外来/本厂)、状态下拉(6种+驳回)、搜索框、日期范围
- 表格：☐/批次号/类型/客户/投料日/出钢日/投料重/出钢重/状态色标/操作

### 7. 冶炼加工详情 `/smelting/:id` (最复杂页面)
- 顶部：返回按钮 + 标题 "冶炼加工单 #批次号" + 状态标签
- **审核信息区** (reviewer/admin 可见)：录入人/时间、审核人/时间、状态、通过/驳回按钮+原因
- **批次信息区**：批次号、类型、客户、投料日期、出钢日期、浇筑残留、残留率、成锭率
- **来料明细子表** (可折叠)：筛选归属 + 表格 (#/日期/钢种规格/重量/归属/操作) + 底部投料总计 + [+添加来料]按钮
  - Modal 1「添加来料」: 左栏可选库存(可筛选)+右栏已选物料(输入用量+单价) → 底部汇总确认
- **出钢明细子表** (可折叠)：表格 (#/日期/钢种规格/炉号/重量/支数/操作) + 出钢总计 + [+添加出钢]
  - Modal 2「添加出钢」: 从物品目录选 OR 手动输入 + 炉号/重量/支数/单价
- **补加合金子表** (可折叠)：筛选归属 + 表格 (#/品种品位/重量kg/单价/金额/归属/操作) + 合金总重总价 + [+添加合金]
  - Modal 3「添加合金」: 左栏可选库存(筛选)+右栏已选(用量kg+单价) → 汇总确认
- **费用汇总区**：来料总价/合金总价/出钢总价/加工金额/小计/税率/税额/合计含税
- 底部按钮栏：[保存] [提交审核] [标记进行中] [标记完成] [导出Excel]

### 8. 外协加工列表 `/outsource`
- 工具栏 (+新建外协批次/批量删除)
- 筛选栏：工艺下拉(锻造/电渣/车光/退火)、状态、外协厂、搜索、日期
- 表格：☐/批次/工艺/外协厂/发出日/回厂日/发出总重/回厂总重/成材率/切锯头/损耗/状态/操作

### 9. 外协加工详情 `/outsource/:id`
- 类似冶炼详情结构，但字段不同：
- 审核信息区 (同冶炼)
- 批次信息区：批次号/工艺/外协厂/加工单价/加工总金额/成材率/切锯头/损耗
- 发出明细子表 + Modal (从本厂仓库选)
- 回厂明细子表 + Modal (从物品目录选 or 手动输入)
- 费用汇总区
- 底部按钮栏

## 第 3 批：其他业务页面 (6 个)

### 10. 采购管理 `/procurement`
- 列表页：工具栏 (+新建采购/批量删除)、筛选 (供应商/日期/状态/搜索)、表格 (☐/#/批次/日期/供应商/材料/规格/量/单价/金额/状态/操作)
- 新建/编辑 Modal：批次号(自动)、供应商、购料日期、材料名称、规格/品位、数量/单位、单价/金额

### 11. 销售管理 `/sales`
- 类似采购结构
- 列表：工具栏/筛选/表格(☐/批次/发货日/客户/钢种/规格/重量/支数/单价/金额/状态/操作)
- Modal：批次号(自动)、发货日、客户、钢种/规格、重量/支数、单价/金额

### 12. 库房管理 `/inventory` (两个 Tab)
- **Tab 1「当前库存」**: 工具栏(+入库/-出库/盘点调整/批量删除)、筛选(类型/归属/搜索)、表格(类型/钢种材料/规格/归属/客户/支数/重量/单价/金额/操作)
  - 入库 Modal、出库 Modal、盘点调整 Modal (各独立)
- **Tab 2「变动记录」**: 只读、筛选(日期/类型/物品搜索)、表格(日期/类型/物品/规格/变化支数/变化重量/变化前支数/变化前重量/变化后支数/变化后重量/操作人)

### 13. 用户对账 `/reconciliation`
- 列表页：工具栏 (+新建明细/+从订单导入/批量删除)、筛选(往来单位/日期/对账状态/发票状态)、表格(多列：☐/#/批次/日期/摘要/钢种/重量/支数/单价/应收款/应付款/付款日/付款金额/付款方式/发票状态/操作)
- 底部合计行：应收/应付/已付/余额/开票汇总 + [标记为已对账][导出对账单Excel]
- 新建/编辑 Modal：往来单位/账期/业务信息(日期/摘要/钢种/重量/支数/单价/应收/应付/差额)/付款信息(日期/金额/方式)/发票信息(状态/日期/金额)/备注
- 从订单导入 Modal：选择单位+类型 → 可选订单列表 → 导入预览 → 确认

### 14. 财务中心 `/finance` (两个 Tab)
- **Tab 1「往来余额表」**: 筛选(类型/搜索)、表格(单位/类型/应收总额/已收总额/应付总额/已付总额/余额)
- **Tab 2「收付款明细」**: 筛选(方向/单据类型/日期/搜索)、表格(☐/日期/方向/单位/关联批次/类型/金额/方式/操作人/备注/操作)

### 15. 审核中心 `/audit`
- 筛选：类型(冶炼/外协/采购/销售)
- 表格：☐/类型/批次/单位/金额/录入人/时间/状态/操作(审核按钮)
- 审核弹窗：详情摘要 + 通过/驳回(需原因)

### 16. 操作日志 `/operation-logs` (admin only)
- 筛选：时间/操作人/操作类型/对象类型/搜索
- 表格：时间/操作人/操作/对象/摘要/变更详情(查看)
- 变更详情弹窗：操作人/时间/IP + 变更内容(JSON格式化)
